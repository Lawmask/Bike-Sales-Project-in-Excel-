# Bike Sales Data Analysis & Dashboard

## Project Overview

This project is an **Excel-based data analysis and visualization project** focused on cleaning, analyzing, and presenting insights from a bike sales dataset.

The dataset contains **1,027 records** and was sourced from **Kaggle**. The project demonstrates a complete basic data-analysis workflow: preserving the raw dataset, cleaning and preparing the data, creating a working sheet, summarizing the data with Pivot Tables, and building a dashboard for visualization.

## Objectives

The main objectives of this project were to:

- Clean and prepare the bike sales dataset for analysis.
- Review and organize the different columns in the dataset.
- Create a separate working sheet for data preparation.
- Use Pivot Tables to summarize and analyze the data.
- Build an interactive Excel dashboard.
- Identify patterns in bike purchases across customer demographics.
- Analyze the relationship between income, commute distance, and bike purchases.
- Present the findings in a clear and easy-to-understand visual format.

## Dataset

- **Source:** Kaggle
- **Number of records:** 1,027
- **Domain:** Bike Sales
- **Format:** Excel/CSV

The dataset contains customer and purchasing information such as:

- Gender
- Marital Status
- Education
- Region
- Income
- Age/Age Bracket
- Commute Distance
- Purchased Bike

The original/raw dataset was retained separately so that the cleaned data can be checked against the original data if issues are discovered later.

## Project Workflow

### 1. Raw Dataset

The original bike sales dataset was preserved before any modifications were made.

### 2. Working Sheet

A separate working sheet was created to clean and prepare the data while keeping the original dataset intact.

### 3. Pivot Table

Pivot Tables were created to summarize the dataset and make it easier to compare customer characteristics and purchasing behavior.

### 4. Dashboard

The cleaned and summarized data was used to create an Excel dashboard containing charts and interactive filters/slicers.

The dashboard allows the data to be explored by categories such as:

- Marital Status
- Region
- Education
- Gender
- Age Bracket
- Income
- Commute Distance
- Purchased Bike

## Dashboard Analysis

The dashboard was designed to answer questions such as:

### 1. Which age group bought the most bikes?

The dashboard compares bike purchases across **Adolescent, Middle Age, and Old** customer groups. The **Middle Age** group shows the highest level of bike purchases.

### 2. Which gender had the highest purchases?

The dashboard provides gender-based comparisons of customers who purchased bikes, allowing male and female purchasing behavior to be evaluated.

### 3. Which region generated the most sales?

The dashboard includes a **Region** filter that allows sales and purchasing behavior to be analyzed across:

- Europe
- North America
- Pacific

### 4. What is the average income of customers?

The dashboard compares average income by gender and purchase status. Customers who purchased bikes can be compared with those who did not purchase.

### 5. What is the relationship between commute distance and bike purchases?

The **Customer Commute** chart compares bike purchases across commute-distance categories:

- 0–1 Miles
- 1–2 Miles
- 2–5 Miles
- 5–10 Miles
- More than 10 Miles

This helps identify how commuting distance relates to bike purchasing behavior.

## Key Findings

Based on the dashboard analysis:

- The **Middle Age** customer group recorded the highest number of bike purchases.
- The dashboard shows differences in purchasing behavior between male and female customers.
- Regional purchasing performance can be compared using the Region filter.
- Average income differs between customers who purchased bikes and those who did not.
- Bike purchases vary across different commute-distance categories, showing a relationship between commuting distance and purchasing behavior.
